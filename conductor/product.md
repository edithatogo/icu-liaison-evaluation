# Product

This project supports a draft clinical and economic evaluation of an ICU liaison
service. The intended users are clinical, service-planning, research and Finance
reviewers. It provides explicit cohort/outcome contracts, traceable assumptions,
cost-consequence scenarios, synthetic capacity diagnostics and reviewable reports.

Current source comprises P0–P8 and the companion P7 placeholder workflow. The
repository is the owner of this evaluation's consumer code. Dapane owns exact
valuation; Voiage owns VOI; Kairos owns scheduling; MCHS owns its annual activity
calculator; the workforce provider owns roster quotation rules. Their source
pins and acceptance gates are retained in the project contracts.

The immediate deliverable is a reproducible source repository using explicit
placeholders for missing information. It is not an approved local model,
clinical deployment, investment recommendation or evidence of savings.

Approved CHHHS data, intervention effects, workforce/cost estimates, native
provider receipts and independent clinical/economic/Finance reviews are later
admission tasks under the existing tracks. Do not replace them with invented
values or interpret the synthetic fixtures as hospital observations.
