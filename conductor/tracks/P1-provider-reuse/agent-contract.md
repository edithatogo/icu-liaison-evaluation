# Scope and ownership

This portable work may edit only its own Python adapter and provider validation
files, public synthetic inputs/tests, documentation and the P1 Conductor record.
The eventual private evaluation repository is not supplied, so no PR, remote
Conductor installation, production deployment, GitHub merge or suite-level
change is authorised or claimed here.

Do not alter Dapane, Voiage, CareOps Sim, Kairos or CareOps Finance upstream
sources. Third-party installed packages are not agent authority. Any source
revision change must be independently reviewed and requalified. No protected
hospital data, staff information, credentials or verbatim conversations are
stored in the portable archive.
