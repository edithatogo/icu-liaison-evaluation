# P1 risk and limitations

- Dapane `0.1` is an unpublished native wheel; a Git source SHA and Python
  distribution version do not prove installed binary provenance.
- Voiage `3.1.0` needs CPython >=3.15.2; this runtime was not available in the
  portable container. Do not substitute an imported fake or an older release.
- Dapane values reported resource quantities, not epidemiological causality,
  genuinely avoidable costs, or hospital bed release.
- The bridge constructs marginal counterfactual *difference* ledgers, not full
  patient-level pathways. Neither quantity can be counted again in a more
  comprehensive resource ledger.
- Rounding needs exact decimal quantities, not unreviewed binary float strings.
  Price year, currency, perspective, basis and source validation must agree.
- A reduction in ICU returns is not necessarily desirable; negative values
  represent additional early returns after surveillance and may be beneficial.
- Voiage EVPI describes one annual programme choice under resource-only
  uncertainty; it is not an ICER, health-gain EVPI, per-patient EVPI, or
  automatically a population-level value of research.
- Synthetic two-state test oracles and injected calculation providers are
  necessary regression tests but do not qualify real native distributions.
- Current P1 results do not establish clinical safety, net cash savings,
  transportability, or confidence intervals for Cairns.
