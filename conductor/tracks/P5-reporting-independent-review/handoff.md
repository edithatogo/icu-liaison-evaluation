# P5 handoff

P5 produces a complete portable source and sample-report directory, with
cash/resource/capacity separation, resource arithmetic audit, provenance,
file hashes and explicit unavailable-provider/safety status. No new generic
VOI, costing, simulation or database engine was created. All P0–P4 work is
preserved. To promote beyond synthetic source acceptance, require authorised
CHHHS source extracts, installed Dapane/Voiage, independent reviewer analysis,
exact GitHub checks and clinical/Finance sign-off in the dedicated repository.

## Additional local source completion — 18 November 2026

Implemented an opt-in Dapane native execution boundary with two-cent point-input
reconciliation, a no-fallback `--dapane` switch, and a separate independent P5
report consumer which recalculates summary and paired results from published
draws. The native library and binary provenance are not verified; injected
provider tests are **contract-only**. External clinical, Finance, ANZICS report
source and exact-hosted acceptance gates are unchanged. P6 event-trace admission
is a separate synthetic-only capability.
