# P5 handoff

P5 produces a complete portable source and sample-report directory, with
cash/resource/capacity separation, resource arithmetic audit, provenance,
file hashes and explicit unavailable-provider/safety status. No new generic
VOI, costing, simulation or database engine was created. All P0–P4 work is
preserved. To promote beyond synthetic source acceptance, require authorised
CHHHS source extracts, installed Dapane/Voiage, independent reviewer analysis,
exact GitHub checks and clinical/Finance sign-off in the dedicated repository.
