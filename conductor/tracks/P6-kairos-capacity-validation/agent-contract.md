# P6 ownership

This project owns only its **synthetic input contract, trace acceptance,
mechanical numeric tests and methodological notes**. Kairos alone owns its
scheduler and discrete-event engine; neither this portable package nor the
future business-case repository may duplicate or modify it as part of P6. No
CareOps Suite, Dapane or Voiage internals may be edited under this track.

The dedicated public GitHub repository carries the synthetic consumer and
fixtures. The exploratory careops-sim PR #215 retains its recorded migration
disposition. Private observations and vendor datasets stay in approved storage.
